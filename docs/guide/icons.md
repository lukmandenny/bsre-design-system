# Phosphor Icons

Untuk urusan ikonografi, **BSrE Design System** menggunakan [Phosphor Icons](https://phosphoricons.com/). Ikon ini dipilih karena opensource & openlicense, selain itu juga set icon ini memiliki desain yang _clean_, profesional, dan punya banyak variasi ketebalan (Regular, Bold, Fill, dll).

Set icon 2D dipilih dibandingkan 3D karena skalabilitas dan konsistensi desainya yang lebih baik.

## Cara Pasang (Vue 3)

Kalau kamu menggunakan ekosistem Web (Vue), install _package_ resminya terlebih dahulu:

```
npm install @phosphor-icons/vue
```
